# Le Courrier — plan de construction

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un jeu de Créer où Joyce et Jade s'envoient des lettres (dessin, texte, autocollants, voix) sur une seule tablette.

**Architecture:** La logique (états des lettres, file de la boîte, texte, gestes) est pure et testée dans `src/core/` ; le stockage est une interface à deux réalisations (IndexedDB, mémoire). Le jeu (`src/games/courrier*.ts`) est une scène 3D (les deux boîtes) sous des écrans DOM (feuille, cérémonie, lecture). Les pinceaux sortent de l'Atelier pour être partagés.

**Tech Stack:** TypeScript strict, three.js par `core/three3d.ts`, canvas 2D, MediaRecorder, IndexedDB, vitest (environnement node), Playwright (smoke et bots). Aucune dépendance nouvelle.

**Spec:** `docs/superpowers/specs/2026-11-25-courrier-design.md` (cité « § n »). La maquette `.maquette/courrier/` fait foi pour les gestes et l'allure ; elle se lit, elle ne se copie pas telle quelle (§ 7).

## Global Constraints

- Lire `CLAUDE.md`, puis `PIEGES.md` par domaine (toucher, voix et sons, 3D, bots) avant chaque tâche qui y touche.
- Français partout : textes, commentaires, commits d'une ligne. Aucun `Co-Authored-By`.
- À chaque commit, dans chaque fichier modifié qui porte `@version` (et en tête de tout fichier nouveau) : `date "+%Y-%m-%d %H:%M"`.
- Aucun texte d'instruction dans le jeu ; chaque bouton porte son petit nom (`.tool-item` / `.tool-cap`).
- Aucun réseau. Ni « vu », ni nombre, ni notification ; le drapeau ne se voit que dans le jeu. Pas de téléphone ni de petits messages.
- Vrais émojis : contenu écrit par les filles, touche et onglet « émojis » ; nulle part ailleurs.
- `ctx.say` : texte tapé par une fille, sur un toucher ; jamais une consigne.
- Feuille 1500 × 1000 ; 40 objets et 5 voix par lettre ; voix de 0,4 s à 30 s ; annuler : 12 gestes.
- Minuteurs par `ctx.after` / `ctx.every` ; `ctx.alive()` après chaque `await` ; nettoyage idempotent.
- Voiles d'arène à `z-index` 7 au plus ; rien sous la barre de la coquille ; pas de `backdrop-filter` sur la 3D.
- Clés neuves seulement : base `ferme-courrier`, `localStorage` `ferme:courrier:*`.
- Chaque tâche finit par `npm run build && npm run lint && npm test` au vert, puis un commit.
- Scripts `.verify-*.mjs` : supprimés avant commit ; toute commande longue sous `timeout` avec une ligne par élément (règle 6).

## Review Focus

1. **Deux doigts à la fois sur la cérémonie** (un sur « Envoyer », un sur l'enveloppe ; double toucher) : une seule lettre part, une seule fois. → tâche 11
2. **On sort au mauvais moment** (maison ou « rejouer » de la coquille pendant un pli, une pose de cire, ou pendant que le micro demande l'autorisation) : micro fermé, brouillon ou enveloppe cachetée retrouvés. → tâches 4 et 11
3. **Du vide** (espaces et retours seuls dans un texte) : rien n'est envoyé, aucun objet fantôme ne reste. → tâches 2 et 10
4. **Un morceau illisible** (dessin ou voix corrompus) : la lettre s'ouvre sans lui, la boîte n'est pas bloquée. → tâche 12
5. **La pause tombe pendant un geste tenu** (minuteur parental, onglet caché) : le geste est annulé, rien ne part, la voix en cours est gardée. → tâches 4 et 11
